# Checklist de revision de imagenes

Usa esta lista antes de aprobar cualquier imagen para publicacion.

## Fuente y derechos

- [ ] La pagina original fue abierta.
- [ ] La imagen no se tomo directamente desde Google Imagenes.
- [ ] El autor esta identificado.
- [ ] El titular de copyright esta identificado o razonablemente documentado.
- [ ] La licencia exacta esta identificada.
- [ ] La licencia permite uso comercial.
- [ ] La licencia permite modificaciones, o la imagen se usa sin modificar.
- [ ] La atribucion requerida esta documentada.
- [ ] La URL de la licencia esta guardada.
- [ ] La fecha de consulta esta registrada.
- [ ] No hay restricciones adicionales evidentes.

## Privacidad y seguridad

- [ ] No contiene correos personales.
- [ ] No contiene nombres de usuario reales.
- [ ] No contiene credenciales, tokens, claves o secretos.
- [ ] No contiene tenant IDs, rutas internas, datos de clientes o informacion empresarial privada.
- [ ] No contiene IPs publicas identificables.
- [ ] No contiene MAC, hostnames o identificadores persistentes sin redactar.
- [ ] Si se redacto contenido, la licencia permite modificaciones.

## Calidad visual

- [ ] Muestra el paso exacto o una parte claramente relacionada del flujo.
- [ ] La version del sistema o aplicacion coincide con el articulo, o la diferencia se explica en el pie.
- [ ] La imagen es legible en movil y al ampliarla.
- [ ] No esta deformada.
- [ ] No se recorto informacion relevante.
- [ ] No tiene marcas de agua no autorizadas.
- [ ] Tiene texto alternativo descriptivo.
- [ ] Tiene pie de imagen.

## Registro

- [ ] Existe entrada en `content/image-attributions.json`.
- [ ] `reviewStatus` es `approved`.
- [ ] `commercialUseAllowed` es `true`.
- [ ] `modificationsAllowed` refleja la licencia real.
- [ ] `shareAlikeRequired` refleja la licencia real.
- [ ] `modificationsMade` explica cualquier redaccion, compresion, conversion o recorte.
- [ ] La pagina `/creditos-de-imagenes` muestra el credito correctamente.

## Resultado

- [ ] Aprobada.
- [ ] Rechazada por licencia.
- [ ] Rechazada por privacidad.
- [ ] Rechazada por no coincidir con el paso.
- [ ] Pendiente de captura propia segura.
