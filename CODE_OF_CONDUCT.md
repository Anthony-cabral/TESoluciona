# Código de conducta

Tesoluciona debe ser un proyecto útil, respetuoso y seguro para colaborar.

## Estándar esperado

- Tratar a otras personas con respeto.
- Argumentar decisiones técnicas con evidencia.
- Evitar lenguaje discriminatorio, abusivo o intimidante.
- Reportar problemas de seguridad por canales privados.

## Aplicación

Los mantenedores pueden cerrar conversaciones, rechazar cambios o retirar acceso cuando una contribución ponga en riesgo a usuarios, colaboradores o la integridad del proyecto.
